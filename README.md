# 🚀 DraftYard

> **AI-Powered Collaborative Platform for Reviving Startup Ideas**

DraftYard is an AI-powered platform that helps developers validate new ideas, revive unfinished projects, and collaborate with like-minded builders. It combines Hybrid Retrieval, Google Gemini AI, semantic search, and community collaboration to transform isolated ideas into successful products.

---

## ✨ Features

### 🤖 AI-Powered Idea Review
- AI feasibility analysis
- Market potential evaluation
- Risk assessment
- Tech stack recommendations
- Improvement suggestions

### 🔍 Hybrid Semantic Retrieval
- Sentence Transformer embeddings
- Vector similarity search
- Metadata-aware re-ranking
- Similar project discovery

### 📂 Draft Workspace
- Project management
- Tasks & milestones
- Team collaboration
- Progress tracking

### 🌍 Community Platform
- Discover projects
- Request collaboration
- Revive abandoned ideas
- Community insights

### 📊 Intelligent Insights
- Stack Intelligence
- Analytics dashboard
- AI Assistant
- Personalized recommendations

### 🔐 Secure Authentication
- JWT Authentication
- Google OAuth 2.0
- Role-Based Access Control
